# Galaxy 3D 🌌✨

A browser‑based 3D galaxy visualization created using pure HTML, CSS, and JavaScript. This project contains multiple versions of a particle‑based galaxy effect, each exploring different motion patterns, visual styles, and depth simulations.

## 🚀 Overview
This repository serves as a creative sandbox for experimenting with:
- 3D‑style particle motion  
- Rotational galaxy effects  
- Layered depth and perspective  
- Color gradients and glow effects  
- Lightweight animation techniques  

Each HTML file represents a unique iteration of the galaxy concept.

## 📁 Project Structure

3D galaxy 0.html
3D galaxy 1.html
3D galaxy 2.html
3D galaxy 3.html


These versions explore differences in:
- Particle density and distribution  
- Rotation speed and animation curves  
- Color palettes and glow intensity  
- Depth simulation and layering  
- Overall visual complexity  

## ▶️ How to Use
1. Clone or download the repository  
2. Open any `.html` file in your browser  
3. Watch the galaxy animation in motion  
4. Compare versions to see how the effect evolves  

## 🛠 Customization
Because the project uses no frameworks or dependencies, you can easily:
- Adjust particle counts  
- Change color themes  
- Modify animation timing  
- Add interactivity (mouse movement, controls, etc.)  
- Combine features from different versions
